# MTGA Account Tracker

This folder is the independent project root for MTGA Account Tracker, a planned static GitHub Pages application. The parent workspace instructions also apply.

- Keep Git operations, dependencies, configuration, and application files within this project.
- No framework or feature specification has been selected. Establish the requirements with the user before implementing the tracker or choosing dependencies.
- Keep account data, credentials, and personal exports out of version control. Use synthetic data for committed examples and tests.
- Produce static output, account for the eventual repository URL prefix, and use routing compatible with GitHub Pages.
- Once tooling exists, document and run the relevant preview, production build, and verification commands.
- Repository creation, pushes, and deployment require authorization from the user's task.
